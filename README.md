# Language Translation Tool

## Overview
The Language Translation Tool is a Python-based application that enables users to translate text from one language to another. It uses Google Translator services to provide accurate translations through a simple and user-friendly interface.

## Features
- Translate text between multiple languages
- Fast and accurate translations
- Easy-to-use graphical interface
- Supports various language combinations

## Technologies Used
- Python
- Tkinter
- Deep Translator

## Installation

Install the required library:

```bash
pip install deep-translator
```

## Usage

Run the application:

```bash
python translator.py
```

### Steps
1. Enter the text you want to translate.
2. Select the source language.
3. Select the target language.
4. Click the Translate button.
5. View the translated text.

## Applications
- Language learning
- Travel assistance
