# Object Detection Using YOLOv8

## Overview
This project performs real-time object detection using a webcam and the YOLOv8 deep learning model. It identifies and labels objects in live video streams with high accuracy.

## Features
- Real-time object detection
- Object labeling
- Bounding box visualization
- Webcam integration
- Fast and accurate performance

## Technologies Used
- Python
- OpenCV
- YOLOv8
- Ultralytics

## Installation

Install the required libraries:

```bash
pip install ultralytics opencv-python
```

## Usage

Run the application:

```bash
python object_detection.py
```

### Steps
1. Start the program.
2. Allow webcam access.
3. The system detects and labels objects in real time.
4. Press 'Q' to exit the application.
