# FAQ Chatbot

## Overview
The FAQ Chatbot is an AI-based application designed to answer frequently asked questions. It uses predefined questions and answers to provide quick and accurate responses to users.

## Features
- Interactive chatbot interface
- Instant responses to FAQs
- Easy to customize and extend
- Lightweight and beginner-friendly

## Technologies Used
- Python
- Basic NLP Concepts
- Dictionary-Based Knowledge Base

## Installation

No additional libraries are required for the basic version.

## Usage

Run the chatbot:

```bash
python faq_chatbot.py
```

### Steps
1. Start the chatbot.
2. Enter a question.
3. Receive the corresponding answer.
4. Type "exit" to end the conversation.

## Applications
- Customer support systems

- Help desk automation
